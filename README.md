# Teaching Repository / Kho lưu trữ bài giảng

## 🇬🇧 English

This repository is used to store the code files from the class sessions I teach at school. Nothing particularly exciting here, but it's also a way for me to practice with Git.

## 🇻🇳 Tiếng Việt

Repository này dùng để lưu lại các file code qua các buổi mình đi dạy tại trường. Không có gì hấp dẫn nhưng cũng là một cách để luyện tập với git.

---

### 📚 Contents / Nội dung

Code files are organized by session or topic. Feel free to browse around.

Các file code được sắp xếp theo buổi học hoặc chủ đề. Cứ thoải mái xem qua.

- Java Swing
- MySQL
